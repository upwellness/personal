นิสัยเก่า vs นิสัยใหม่

เป้าหมายคือเปลี่ยนบทบาทจาก “ผู้เสนอ” เป็น “ผู้ถามที่ช่วยให้เขาเห็นคำตอบเอง”

นิสัยเก่า

  • มีเป้าหมายในใจตั้งแต่เริ่ม
  • ถามนิดเดียวแล้วรีบชวน
  • หว่านล้อมเมื่อถูกปฏิเสธ
  • จบด้วยความอึดอัด

นิสัยใหม่

  • ถามไปเรื่อย ๆ อย่างจริงใจ
  • ฟังให้จบก่อนถามต่อ
  • ให้เขาเสนอความคิดของตัวเอง
  • ส่ง message เมื่อข้อมูลครบ
MTM: Modernize The Message Sponsor07/18

หลักการถามที่ดี

คำถามที่ดี จะได้คำตอบที่ดี — แต่คำถามต้องไม่ทำให้เขารู้สึกถูกคุกคาม

ควรทำ

  • ถามทีละคำถาม
  • ตั้งใจฟังให้จบ
  • ถามด้วยความห่วงใยและเข้าใจ
  • ใช้ “เป็นอย่างไร” มากกว่า “ทำไม”
  • สรุปเพื่อยืนยันว่าเข้าใจถูก

ควรหลีกเลี่ยง

  • คำถามเชิงแนะนำหรือโน้มน้าว
  • ตัดบทก่อนเขาพูดจบ
  • ทำให้เขารู้สึกถูกข่มหรือถูกต้อน
  • วิจารณ์ความคิดของเขาเร็วเกินไป

F: Family / Fact Finding

อุ่นเครื่อง รื้อฟื้นความสัมพันธ์ และเข้าใจว่า “ตอนนี้เขาเป็นอย่างไร”

เป้าหมายของ F

  • ทำให้เขารู้สึกว่า
  • คุยกับเราสนุก
  • เราใส่ใจจริง
  • และยังคุยกันต่อได้

คำถามเปิด

  • เป็นไงบ้าง?
  • ช่วงนี้ทุกอย่างโอเคไหม?
  • งานเป็นยังไง?
  • ครอบครัว/ลูก/สุขภาพโอเคไหม?

วิธีจบที่ดี

  • สรุปเรื่องของเขาเล็กน้อย
  • ทิ้งบทสนทนาไว้ให้ต่อได้
  • ขอเบอร์/นัดคุยครั้งถัดไป
  • กลับไปเตรียมคำถามเพิ่ม

O: OK / Outcome

“แล้วที่โอเคคืออะไร?” — ให้เขาเห็นเป้าหมายและความจริงจังของตัวเอง

ประเด็นที่ต้องชัด

  • เขาแค่บ่น หรือจริงจังกับการแก้ปัญหา?
  • เขาเคยคิดจะทำอะไรไปแล้วบ้าง?
  • Project ในฝันของเขาชัดแค่ไหน?
  • ผลตอบแทนตอบโจทย์จริงหรือไม่?

ตัวอย่างคำถาม

คิดว่าจะทำยังไง?

ต้องเห็นผลเมื่อไร?

ต้องลงทุนเท่าไร เสี่ยงไหม?

ผลตอบแทนแก้ปัญหาได้ไหม?

R: Recreation / Reality Check

สำรวจเวลาจริง ความพร้อมจริง และสิ่งที่เขายอมแลกเพื่อเป้าหมาย

1

เวลา

ทำงานกี่วัน เลิกงานกี่โมง หยุดวันไหน จะจัดเวลาตอนไหน?

2

พลัง

ทำควบคู่กับงานเดิมไหวไหม ถ้าไม่สำเร็จจะกลับไปทำอะไร?

3

ความคุ้มค่า

รายได้ที่จะได้คุ้มไหม ตอบโจทย์ระยะสั้นและระยะยาวไหม?

ไฟแดงยังแดงอยู่: ถึงตรงนี้ยังไม่ต้องรีบ Sponsor ถ้าข้อมูลและจังหวะยังไม่พร้อม

M: Message

เมื่อเข้าใจครบแล้ว จึงส่งสารชัดเจน อ่อนน้อม และไม่กดดัน

สิ่งที่เรารู้ก่อนส่ง Message

  • ปัญหาที่ชัดเจน
  • สิ่งที่เขาต้องการ
  • เวลาและการจัดการตัวเอง
  • เงื่อนไขในใจ/ปมค้าง
แกนของ Message
  • เราไม่ได้คุยกันเรื่อง “งานที่ชอบ” เท่านั้น
  • แต่กำลังคุยกันเรื่อง “งานที่ใช่”
  • คือทางเลือกที่อาจแก้ปัญหาของเขาได้
MTM: Modernize The Message Sponsor13/18

Script ตัวอย่างช่วงส่ง Message

ใช้เป็นแนวทาง ไม่ใช่ท่องจำ — ปรับจากข้อมูลที่เขาเล่าจริง

1

ทวน

“เมื่อกี้คุณบอกว่า… และสิ่งนี้สำคัญกับคุณเพราะ…”

2

เชื่อม

“ถ้าวิธีที่คิดไว้ยังไม่ตอบโจทย์ แล้วมีอีกทางที่ช่วยได้ใน 2–3 ปี คุณเปิดใจดูไหม?”

3

เสนอ

“ผมเข้าใจว่าคุณไม่ชอบงานขาย/ไม่ชอบแอมเวย์ แต่ถ้ามันช่วยแก้ปัญหานี้ได้ ทำไมไม่ลองดู?”

4

ปิดแบบไม่กดดัน

“ลองดูไหม ผมอาจช่วยคุณได้” แล้วให้พื้นที่เงียบ 5–10 วินาที

การตอบข้อโต้แย้ง

ตอบด้วยคำถามกลับ เพื่อช่วยให้เขามองทางเลือก ไม่ใช่เอาชนะว่าใครถูก

1

ยอมรับ

รับรู้ว่าความไม่ชอบหรือความลังเลยังมีอยู่จริง

2

ถามกลับ

ใช้คำถามช่วยให้เขาคิดต่อ แทนการเผชิญหน้า

3

วางไว้ก่อน

ถ้าความไม่ชอบยังอยู่ แต่มันแก้ปัญหาได้ เขาจะลองดูไหม?

4

รักษาความสัมพันธ์

อย่าทำให้เขารู้สึกว่าเขาผิดหรือถูกต้อน

การทำรายชื่อ: เขียนหรือไม่เขียน ต่างกันมาก

รายชื่อไม่ใช่แค่ list คนรู้จัก แต่คือระบบวางแผนและติดตามงาน Sponsor

ทำไมต้องเขียน

  • ไม่ลืมใคร
  • เห็นความเป็นไปได้
  • วางแผนเวลา
  • ไม่เฝ้ารอคนที่ยังไม่พร้อม

รายชื่อเก่าไม่เท่ากับโอกาสเก่า

  • คนที่เคยปฏิเสธอาจมีภาระใหม่
  • เงื่อนไขชีวิตเปลี่ยน
  • วันนั้นกับวันนี้ไม่เหมือนเดิม

ใช้ติดตามบทสนทนา

  • คุยกับใครแล้ว
  • คุยถึงไหนแล้ว
  • ครั้งต่อไปจะถามอะไร
  • ใครอาจรู้จักคนที่ใช่
