01 / ANSWER

คำตอบเร็วใน 60 วินาที

CGM มีคุณค่าสูงเมื่อใช้เพื่อดู “รูปแบบซ้ำ” และตัดสินใจร่วมกับบริบท ไม่ใช่ไล่แก้ตัวเลขทุกจุด

ค่าหลักจากอุปกรณ์

Sensor glucose + เวลา

อัลกอริทึมประเมินกลูโคสจากสัญญาณเซนเซอร์ในน้ำระหว่างเซลล์ ไม่ใช่การวัด plasma glucose โดยตรง

คำนวณจากข้อมูล

TIR · TAR · TBR · CV · GMI

สรุปว่ากลูโคสอยู่ในช่วง สูง ต่ำ และผันผวนเท่าไร ไม่ใช่ผลแล็บชุดใหม่

ตีความอย่างระวัง

อาหาร · นอน · เครียด · ออกกำลัง

เห็นความสัมพันธ์ตามเวลาได้ แต่วันเดียวไม่พิสูจน์เหตุ–ผล ต้องบันทึกและทดลองซ้ำ

03 / METRICS

ค่าอะไรบ้างที่ได้จากการติด CGM?

กดเลือกตัวชี้วัดเพื่อดูว่าเป็น “ค่าจากเซนเซอร์”, “ค่าคำนวณ” หรือ “การตีความ”

3 ชั้นของข้อมูล

1. ประเมินalgorithm-derived sensor glucose + timestamp
2. คำนวณtrend, TIR, mean, CV, GMI, AGP
3. ตีความmeal/sleep/stress response

ยิ่งอยู่ชั้น 3 ยิ่งต้องใช้เหตุการณ์ที่บันทึก การทดลองซ้ำ และผู้เชี่ยวชาญช่วยอ่านบริบท

แปลง % เป็นเวลา/วัน

ตัวอย่างทางคณิตศาสตร์ ไม่ใช่เป้าหมายรายบุคคล; consensus สำหรับผู้เป็นเบาหวานส่วนใหญ่ใช้ช่วง 70–180 mg/dL และต้องมีข้อมูลที่เพียงพอ/เป็นตัวแทน [S01, S18]

07 / SAFETY

สิ่งที่ CGM บอกไม่ได้ และจุดเสี่ยง

การมีข้อมูลมากขึ้นไม่ได้แปลว่าทุกค่าถูกต้องหรือทุกข้อสรุปเป็นจริง

  • วัดน้ำระหว่างเซลล์ จึงมี physiologic/device lag หลายนาทีได้
  • ความแม่นยำลดลงได้เมื่อค่ากำลังเปลี่ยนเร็ว ช่วงต่ำ หรือวันแรก
  • แรงกดทับขณะนอนทำให้เกิด compression low ได้
  • ยาหรือสารรบกวนแตกต่างตามรุ่น ต้องดูคู่มืออุปกรณ์จริง
  • CGM/GMI ไม่ใช่เกณฑ์วินิจฉัยเบาหวานโดยลำพัง
  • กราฟเรียบไม่ได้แปลว่าอาหารครบคุณค่าหรือสุขภาพดีทุกด้าน
  • อาจเกิด alert fatigue ความกังวล หรือแก้ค่าเร็วเกินไป
  • หากค่าไม่ตรงอาการ/ความคาดหมายหรือสงสัย sensor error ให้ตรวจปลายนิ้วเมื่อคู่มือรุ่นนั้นระบุ และอย่าชะลอการรักษาฉุกเฉินเพราะรอค่า CGM [S02]

คำเตือน

ข้อมูลนี้เป็นการศึกษา ไม่ใช่คำแนะนำให้เริ่ม หยุด หรือปรับยา/อินซูลิน หากมีอาการรุนแรง หมดสติ สับสน ชัก หรือสงสัยภาวะน้ำตาลต่ำ/สูงรุนแรง ให้รับการประเมินทางการแพทย์ทันที
